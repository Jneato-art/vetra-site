# Vetra

**The operating system for veterinary care.**

Vetra is the all-in-one software and payments platform built for independent veterinary practices — scheduling, electronic medical records, an AI clinical scribe, client messaging, and integrated payments in one system.

> _Illustrative project for a fictional company._

## This repo

A single-page marketing site for Vetra.

```
index.html      # Landing page (self-contained, no build step)
README.md       # This file
```

## Run locally

It's a static page — just open it:

```bash
open index.html
# or serve it
python3 -m http.server 8000   # then visit http://localhost:8000
```

## Deploy (GitHub Pages)

1. Push to the default branch.
2. Settings → Pages → Source: **Deploy from a branch** → `main` / `root`.
3. Your site goes live at `https://<user>.github.io/<repo>/`.
